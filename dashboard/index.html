    How this was built

    281 PDFs to one tested warehouse

    USVIBER publishes each month's tourism numbers as one-page PDFs. A Python pipeline lists every file through the bureau's public media feed, downloads each one once, and reads every number by its position on the page. dbt models in DuckDB keep the newest printed value for each month, record every revision, and run 30 data tests. One test checks the result against the headline numbers on usviber.org.

    Found along the way: files uploaded under the wrong name, room-night reports printed with last year's labels, island figures that don't add up to the territory total, and a June 2026 occupancy rate of 73.8% that the bureau's own room-night tables put at 44.1%.

    1. 1Discover reports via the WordPress REST API
    2. 2Download with caching and SHA-256 fingerprints
    3. 3Extract numbers by page position with PyMuPDF
    4. 4Load raw text into DuckDB
    5. 5Model, version and test with dbt
    6. 6Export JSON for this page, refreshed monthly
